Instructions
  1. Board: print a checkerboard with a laser printer (many inkjet inks are invisible at 820 nm), glue it flat on a rigid, matte board. Count the inner corners (squares − 1) and measure one square with a ruler.
  2. Cameras: focus both lenses for the working distance and don't touch them after calibrating. Put both cameras in the same sensor mode; don't change mode or flips during the session.
  3. Exposure: open Camera controls, point at the board and press Lock current exposure so no pixels saturate (the board must be crisp: short exposures avoid motion blur).
  4. Capture {{ recommended_pairs }}–20 pairs. The board should fill ¼–½ of the view and be seen by both cameras. Cover the centre, all four corners and the edges, tilt it ±30° in both directions and vary the distance. Hold it still while capturing (a full-resolution still takes 1–2 s). Use Auto capture to capture whenever the board is still and in a new place.
  5. Run the calibration. Aim for an RMS error below 0.5 px; delete pairs with a large error and run again.
  6. Crop distance: RED is mapped onto IR through a plane at this distance (along the IR camera's view). Set the pitch if the cameras look down at the ground. Both can be changed later in the NDVI tab.
  7. Check the Overlay/Edges view on a real scene at the crop distance, fine-tune with Auto offset, then save the profile under a name and load it in the NDVI tab.
  1. Point both cameras at a flat, sharp, well-textured scene at the crop distance (a building wall, a fence with posters, or the crop canopy seen from the working height).
  2. Lock the exposure (Camera controls) so nothing saturates.
  3. Capture one pair and run: the ECC homography is estimated from the last pair. Correlation above 0.9 is good.
  4. This only holds at that distance and does not model lens distortion. For a durable calibration use the checkerboard method.
